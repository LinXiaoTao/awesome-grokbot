[English](README.md) | 中文

> 精选最佳 [Grok Bots](https://x.ai/bot) 列表 — 基于 xAI Grok 平台构建的 AI 助手。

[Grok Bots](https://x.ai/bot) 是 xAI Grok 平台上的 AI 助手。每个机器人都是具有独立个人资料、集成和例行程序的专用代理 — 专精一项工作，从管理收件箱到审查拉取请求。本列表将社区构建的最佳 Grok Bots 汇集一处。

## 效率

邮件、日历、任务管理和写作类机器人。

- **[Product Idea Stress Test](#product-idea-stress-test)** by @hnshah — 为创始人调研产品或创业想法，揭示必须成立的条件、正反证据、最可能致命的假设以及下一步行动。
- **[Newsletter Cleanup](#newsletter-cleanup)** by @scheemunai — 将所有内容分桶到可读的审查页面，然后根据你的决定采取行动。它取消订阅而非删除，因此收件箱中不会丢失任何内容。
- **[Critiquito](#critiquito)** by @mamuso — 产品设计评论家，从使用者角度审查界面截图，指出不清楚、困难或苛刻之处，并选择一个影响最大的修复。
- **[AIUsageBot](#aiusagebot)** — 访谈你追踪哪些 AI 订阅以及剩余额度在哪里，然后推送剩余百分比。
- **[Bot inbox](#bot-inbox)** by @waynesutton — Grok Bots 的工作日未读摘要，列出有新活动的机器人和群聊，每行一条。
- **[Dispatch](#dispatch)** by @FilippoFonseca — 如果有人同意通话但没有邀请，它会创建日历事件，填补「说好却永远没有安排」的空白。
- **[Google Agent](#google-agent)** by @ryanthawks — 自由搜索和阅读你的邮件、文件和事件，在发送、删除或移动任何内容前停止并等待明确确认。这种不对称性就是整个设计。
- **[Grok Bot Coach](#grok-bot-coach)** — 帮你设计、审计和调整 Grok 机器人，使其可用且有用。从个人资料中的具体工作、正确的连接器和日常工作流程开始。
- **[grokbots.best](#grokbots-best)** — 将公开的 Grok Bot 模板提交到 grokbots.best 目录。
- **[Human Copywriter](#human-copywriter)** — 人类语气改写台，用于邮件、帖子、博客、私信、落地页正文和新闻稿。
- **[Inbot](#inbot)** by @matt_silberman — 设置时连接邮件、Slack 或 Teams、日历、Notion 和消息应用，然后逐一处理。
- **[Pitch Deck Coach](#pitch-deck-coach)** by @hnshah — 上传演示文稿，报告哪些内容有效、哪些被相信、哪些引发疑问、哪些在会议后仍然成立，然后帮你打磨故事。
- **[Reaper](#reaper)** — 找出不再值得存在的重复工作、工具、流程和义务。
- **[Rutin](#rutin)** by @naoufal_elh — 周一早晨优化器，扫描每个机器人的例行程序并提出日程修复建议。
- **[Spark (Onboarding)](#spark-onboarding)** by @vincentzhu — 问一组简短问题，创建匹配你答案的机器人，然后引导你连接账户。

## 编程

开发者工具、代码审查和工程工作流。

- **[AI Harness Assistant](#ai-harness-assistant)** — 让你已使用的 AI 编程工具（Codex、Claude Code、Grok Build、OpenCode、Cursor 等）保持最新，仅更新已安装的工具。
- **[loops](#loops)** — 通用工程外循环。位于编码代理之上，以 pstack 为参考，编写带可测试证明的目标式提示并运行循环。
- **[Apps](#apps)** by @waynesutton — 一键 Convex Web 应用。说「给我建一个聊天应用」，它会搭建 Vite + React + TypeScript 和 Convex 后端。
- **[Cursor Agent](#cursor-agent)** — 仅本地构建器。在用户笔记本电脑上运行 cursor-agent CLI 进行实验和车间 CLI，GitHub PR 仍默认使用云代理。
- **[Dr Eggbot](#dr-eggbot)** by @poteto — 问几个偏好问题，然后生成结构完善的机器人而非空白模板。
- **[Examiner](#examiner)** — 维护重要变更的可靠时间线，以便重建发生了什么。
- **[Forge (Template Foundry)](#forge-template-foundry)** by @rryssf — 给它一个任务或职位描述，第一次就返回完整的机器人配方。
- **[freebots.lol](#freebots-lol)** by @Daniel_Farinax — 以自身身份加入 freebots.lol：自有 Ed25519 密钥、自有页面、签名公告板帖子和工作日心跳。
- **[Gardener](#gardener)** — 清理代码库中的遗留问题。仅做小修复，从不重构，从不改变行为。
- **[PR Reviewer](#pr-reviewer)** by @mustafaergisi — 优先指出可能出错、未测试以及上下文太薄无法判断的部分，让审查从 diff 中最可怕的部分开始。
- **[Professor Oak](#professor-oak)** by @kiaraplds — 实验室外套代理制造者。发明令人难忘的名字，撰写完整职位描述，为每个新代理提供匹配的吉祥物面孔。
- **[Site Audit](#site-audit)** — SEO + 内容 + 速度 + 无障碍 + CRO + schema 审计。评分、P0/P1/P2、证据 URL。每月差异对比。不编造指标。

## 研究

信息收集、分析和竞争情报。

- **[last30days](#last30days)** by @mvanhorn — 研究 Hacker News、YouTube、GitHub 和 Reddit 上过去 30 天人们关于任何话题的实际讨论。
- **[Research Bot](#research-bot)** by @ArthurMacwaters — 从第一性原理推理，拒绝在未经验证的来源下给出答案而不说明，这是研究与自信猜测的区别。
- **[Competitor Watching](#competitor-watching)** — 快照你与 3-8 个竞争对手（定价、更新日志、功能、招聘、信息）的对比，每周差异。
- **[Frontier Model Watch](#frontier-model-watch)** — 关注 xAI、Anthropic、Google、OpenAI、Moonshot、阿里巴巴、智谱、DeepSeek、MiniMax 和腾讯的官方发布，每天 07:30 EAT 发送简短简报。
- **[Interrogator](#interrogator)** — 找出所有者运作所依据的重要假设，并检查它们是否仍然成立。
- **[Lennybot](#lennybot)** by @lennysan — 回答来自 Lenny's Data 档案的问题。
- **[Scout](#scout)** — 有机增长的竞争情报代理。
- **[StoriesBot](#storiesbot)** by @viticci — 长篇评论、Setups 和 Shortcuts 档案，全部可在一个地方查询。另一个创作者档案：语料库是出版物自己的写作。

## 社交

内容创作、社交媒体管理和粉丝互动。

- **[Repost X Posts Everywhere](#repost-x-posts)** by @jackfriks — 通过 Post Bridge 将新的 X 帖子同步到 Threads、LinkedIn、Facebook 和 Bluesky。适合在 X 发帖并希望原创内容遍布各平台的人。
- **[Clip Bot](#clip-bot)** by @ThisWeeknAI — 从 YouTube 剪辑适合社交媒体的播客精彩片段：带卡拉 OK 字幕的 16:9 视频和来源卡片，然后将文件保存到你的电脑。
- **[Clipper](#clipper)** by @thesoragirls — 从 X 或你自己的文件获取素材，观看后判断真正的精彩时刻，为会说话的 GIF 添加字幕。
- **[Growth Desk](#growth-desk)** by @Av1dlive — 仅草稿的 X 增长工作台。你增长一个指定账户。不研究信息流。不发布。
- **[Imogen (Alt Text)](#imogen-alt-text)** by @kentcdodds — 撰写聚焦图像真正重要部分的简短 alt 文本，让帖子保持无障碍。
- **[Shorty](#shorty)** by @farzyness — 从已验证的高表现内容而非所有帖子出发，挑选强力钩子，格式化为 9:16 并加字幕。
- **[X Brief](#x-brief)** by @daniel_mac8 — 首次聊天时连接 X，从你最近的帖子中学习你真正关注的内容，确认该节奏。
- **[X Top 500 Fans](#x-top-500-fans)** — 每月按点赞最多排名你的前 500 名 X 粉丝。

## 财务

预算、优惠、信用卡和费用追踪。

- **[Bounty Hunter](#bounty-hunter)** by @liam_fallen — 寻找已经属于你但未领取的钱：错过的退款、遗忘的积分、多收的款项以及你应得但未追讨的东西。
- **[Credit Card Max](#credit-card-max)** — 建议针对特定购买使用哪张信用卡以最大化积分、返现和福利，跟踪卡片、未用权益和错误路由的定期扣款。
- **[Deal Hunting](#deal-hunting)** — 落地成本购物：真实价格、运费和税费、首选零售商。可选关注列表。除非你要求，否则从不购买。
- **[Lease Finder](#lease-finder)** — 搜索你正在购物的当前租赁优惠，拉取追踪深度折扣的网站。
- **[Point Peddler](#point-peddler)** by @poteto — 唯一的工作是信用卡和航空里程，让你决定如何预订时不超过片刻。
- **[Receipt Scanner](#receipt-scanner)** by @limeunfiltered — 将邮件收据记录到 Google Sheet 和 Drive 文件夹。

## 生活

健康、烹饪、家居、家庭和健身。

- **[Be Happier](#be-happier)** by @lennysan — 每周查看你的邮件和日历，然后建议 3 件能让你更快乐的具体事情。保护现有生活，不增加新习惯。
- **[Chef](#chef)** by @DogecoinNorway — 默认使用当季本地食谱而非流行趋势，将计划转为购物清单并在线下单。
- **[Chicken Joe (Surf Report)](#chicken-joe-surf-report)** by @parker__conrad — 在你醒来前扫描从 Marin County 到 Santa Cruz 的冲浪点，一条消息给出答案而非九个标签页。
- **[Home Robots](#home-robots)** by @SawyerMerritt — 连接每个机器人一次，然后通过一个机器人控制全部，而不是为草坪、地板等分别打开不同应用。
- **[Homework Checker](#homework-checker)** by @kevinace — 放学后总结未完成事项，每当分数下降时提供一次性主题讲解。
- **[Melissa (Fitness & Nutrition Coach)](#melissa-fitness-nutrition-coach)** by @tpgoebel — 实时记录餐食，在催促你更新和让你安静之间取得平衡。
- **[TeslrBot](#teslrbot)** by @HeresMyEth — 通过你在机器人自己的机器上登录的第三方连接器进行控制，无需复制令牌即可访问车辆。
- **[Tradbot](#tradbot)** by @clairevo — 尽管名字如此，它不是交易机器人：它监控你的个人收件箱和日历，防止学校事项、家庭计划和家庭跟进遗漏。

## 企业

团队管理、高管助理和编排协调。

- **[Alfred (Bot Chief Advisor)](#alfred-bot-chief-advisor)** by @heyrobinai — 不是构建一个助手，而是审计你已有的机器人集合并随业务变化重塑组织。
- **[Chieeeeefy](#chieeeeefy)** by @naoufal_elh — 现场工程师的幕僚长。优先处理日历和工作 Gmail，将事件时区转换为用户当前本地时间。
- **[Chief of Staff](#chief-of-staff)** by @Av1dlive — 你是幕僚长。一个大脑。从一张桌子运行此人的一天和公司。
- **[Echo](#echo)** by @kristaletz — 将客户通话转化为基于客户上下文的幻灯片，支持 Figma 或 Google Slides。
- **[Jess (Executive Assistant)](#jess-executive-assistant)** by @LoganARobison — 工作日高管助理：先阅读所有内容，根据书面手册回答员工问题，并发布客户通话笔记，让你开始一天时已了解最新情况。
- **[Kirk (Enterprise Crew)](#kirk-enterprise-crew)** by @The_Mr_Wizard — 星际迷航角色扮演，也是真正的代理团队演示：指挥椅生成作为船员工作的专家。
- **[Kody](#kody)** by @kentcdodds — 跨越人员、项目和其他助手，将你说重要的事真正转化为正在推进的工作。
- **[Leader 1:1 Bot](#leader-1-1-bot)** by @scottxmetcalf — 延续对话线程而非每周重新开始，挑选真正值得占用时段的几个话题。
- **[Master](#master)** — 仅做精简编排。从不拥有工作时钟或保留重复的个人任务，立即路由给专家所有者。
- **[Projects Manager](#projects-manager)** by @ericzakariasson — 启动编码、设计、研究和写作等独立机器人，为每个项目在 Notion 中创建一行和频道，让专家认领任务。
- **[Talent Matchmaker](#talent-matchmaker)** by @lennysan — 从你的邮件中为求职者匹配开放职位，扫描投资者更新和入站邮件中的招聘信号和求职意向，跟踪市场两端。
- **[TheFounder](#thefounder)** by @DaniAcostaAI — 创始人的幕僚长和共享机器的守护者，将工作路由给专家。
